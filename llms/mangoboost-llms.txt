## What MangoBoost ships

- Mango BoostX DPU family — RoCE AI (RDMA), NVMe-oF Initiator (NTI), NVMe-oF Target (NTT),
  TCP Offload Engine (TOE)
- Mango SDK — C/C++ device library (libmango), CLI tools (mango-ctl, mango-smi), OPI gRPC
  storage bridge
- Mango LLMBoost — enterprise LLM inference server with a drop-in OpenAI-compatible REST API,
  running on customer-owned AMD Instinct GPUs

## API surfaces

- [Mango LLMBoost Inference Server API](https://llmboost.mangoboost.io/docs/features/openai-api):
  OpenAI REST API on /v1, default http://localhost:8000/v1. Endpoints: POST /v1/chat/completions,
  POST /v1/completions, POST /v1/embeddings, POST /v1/responses, POST /v1/audio/transcriptions,
  POST /v1/audio/translations, GET /v1/models, GET /health, GET /metrics (Prometheus).
  Streaming, JSON-schema structured output, tool calling and multimodal input are supported.
  Self-hosted — no MangoBoost-operated endpoint exists.
- [Mango SDK Device API (libmango)](https://sdk.mangoboost.io/docs/api/): C/C++ API groups —
  Common, Device Context, Memory, DMA Transfer, TCP/IP Offload, TLS Offload, POSIX,
  AI Image Preprocess, GPU StorageBoost (GSB), RDMA PCC, Software-Defined Device.
- [Mango OPI Storage Bridge gRPC API](https://sdk.mangoboost.io/docs/guide/docs_opi/overview):
  Open Programmable Infrastructure gRPC on :50051 (HTTP gateway :8082). Documented calls —
  CreateNvmeSubsystem, CreateNvmeController, CreateNvmeRemoteController, CreateNvmePath,
  CreateNvmeNamespace. Source: https://github.com/opiproject/opi-mangoboost-bridge

## Authentication

There is none by default. LLMBoost local serving takes no Authorization header
(`api_key="not-needed"`); put it behind your own gateway before exposing it. HF_TOKEN is for
downloading model weights, not for calling the API. The DPU surfaces are host-local or
management-network scoped.
